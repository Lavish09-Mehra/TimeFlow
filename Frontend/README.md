# TimeFlow Frontend

This directory contains the React + TypeScript + Vite frontend and the Capacitor Android project.

For the full project documentation, download link, setup instructions, usage guide, and troubleshooting, see the [root README](../README.md).

## Quick start

```bash
npm install
npm run dev
```

## Build the Android APK

From the repository root:

```bash
./scripts/build-apk.sh
```
